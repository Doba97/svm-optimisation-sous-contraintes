# SVM et optimisation avec contraintes

Projet universitaire de Machine Learning consacré à la formulation
et à la résolution du problème d'optimisation du Support Vector Machine.

## Objectifs
- Étudier le problème primal du SVM.
- Comprendre les contraintes et la convexité.
- Présenter le Lagrangien et les conditions KKT.
- Implémenter et évaluer un SVM en Python.
- Étudier l'influence du paramètre C.

## Organisation
- data/ : données du projet
- notebooks/ : analyses et expérimentations
- src/ : code Python
- tests/ : tests du code
- reports/figures/ : graphiques
- presentation/ : support final
